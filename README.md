# 锚点与留白

👉 **打开 app：<https://peki885.github.io/GL/>**

一个帮你设计「独属于自己的一周」的小 app，基于「锚点 + 菜单 + 留白」框架：

- **本周**：每天的锚点（固定）、弹性（从菜单挑）、留白（什么都不安排）。点开任何一项，做完后打个 1–5 分，再写一句「为什么」。
- **菜单**：让你开心的事，按「滋养感官 / 探索城市 / 创造与输出 / 纯粹快乐 / 连接」分类，可以随时增删。
- **回顾**：按开心程度排序。均分 ≥ 4 的可以一键「设为锚点」，≤ 2.5 的建议删掉。所有写下的「为什么」都在这里。
- **节奏**：每周模板。锚点太多、没有留白时会提醒你。还有备份 / 恢复。

## 使用

纯静态单文件，无需构建：直接用浏览器打开 `index.html` 即可。数据保存在浏览器的 localStorage 里，换设备前请在「节奏 → 备份与恢复」里复制一份备份。

首次打开时会带两周示例记录，方便看回顾页的效果；在「本周」页顶部点「清除示例」即可开始自己的记录。
