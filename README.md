# 锚点与留白

👉 **打开 app：<https://peki885.github.io/GL/>**

> 别人的周计划模板再好看，也不一定适合你。
> 与其照搬，不如自己搭个框架，亲身试上几周，把真正让你开心的事留下来。

## 为什么做这个 app

网上有很多「完美的一周」模板：周一健身、周三读书、周末早起……照着做两周，就开始觉得像在交作业。

问题不在你身上，在于那是**别人**的答案。每个人被什么点亮都不一样，只有你自己的感受说了算。

所以这个 app 不给你标准答案，只给你一个好用的框架，再帮你**记录每件事做完之后你有多开心**。三四周后回头看，哪些事值得留下、哪些可以放下，数据会替你说话。

**目标很简单：慢慢筛出一份独属于你、让你期待每一周的 schedule。**

## 三个核心概念

把一周想象成一首歌 🎵

### ⚓ 锚点：歌里的鼓点

每周固定在某一天做的事，比如周五 Movie Night、周二和周四健身。

它们给生活一个节奏感：还没到周五，就已经开始期待电影夜了。但锚点**不要太多**，2–3 个刚刚好，多了就从「期待」变成「任务清单」了。

### 🍱 菜单：随心点的即兴段落

一份「让我开心的事」清单，比如逛市场、探一家新咖啡馆、乙女游戏夜、给远方的朋友打个电话……

每周日花 5 分钟，看看心情和天气，从里面挑 1–2 个放进弹性时段。今天想出门就选「探索城市」，想窝着就选「纯粹快乐」，没有对错。

### 🌙 留白：歌里的休止符

至少留一个晚上，**什么都不安排**。

留白不是偷懒，而是给自己喘口气的空间。没有留白的计划排得再漂亮，很快也会让人觉得累。在这个 app 里，留白也可以打分：空着的那一晚，你感觉怎么样？

## App 里有什么

| 页面 | 能做什么 |
|---|---|
| **本周** | 看这一周的锚点、弹性、留白。点开任何一项，从菜单挑、或者「随机来一个」；做完后打个 1–5 分，再写一句「为什么」。 |
| **菜单** | 你的开心清单，按「滋养感官 / 探索城市 / 创造与输出 / 纯粹快乐 / 连接」分类，随时增删，删错了还能找回。 |
| **回顾** | 所有做过的事按开心程度排队。平均 4 分以上的可以一键「设为锚点」，2.5 分以下的建议删掉，不需要愧疚。你写过的每一句「为什么」也都在这里。 |
| **节奏** | 编辑每周的默认模板。锚点太多、或者忘了留白时，它会温柔地提醒你。底部的「设置」里可以切换外观（浅色 / 深色 / 跟随系统），也可以备份和恢复数据。 |

## 怎么用

1. **打开**：点上面的链接就能用，不用注册、不用下载。在手机浏览器里选「添加到主屏幕」，它就像一个普通 app 一样待在你的桌面上。
2. **先看看示例**：第一次打开会带两周示例记录，让你先看看「回顾」长什么样。准备好了，就在「本周」页顶部点「清除示例，开始我的记录」。
3. **每周日 5 分钟**：给弹性时段挑好这周想做的事。
4. **做完就打分**：打个分，写一句话，10 秒搞定。
5. **三四周后回顾**：高分的留下或升级成锚点，低分的放手。

## 小提醒

- 你的记录**只存在当前这个浏览器里**，不会上传到任何地方。换手机、换浏览器或清理浏览器数据之前，记得去「节奏 → 设置 → 备份与恢复」复制一份备份。
- 整个 app 就是一个 `index.html` 文件，不需要安装或构建，用浏览器直接打开就能跑。
