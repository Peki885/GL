# 【HAND】Have a nice day~

👉 **打开 app：<https://peki885.github.io/GL/>**

> 独属于自己的周计划

> 搭个框架，尝试几周，将真正让自己感到开心的事留下

## 初衷

**目标很简单：慢慢筛出一份独属于你自己、让你期待每一周的 schedule。**

网上有很多他人的「完美的一周」，很充实、很励志、很鼓舞人心，但当自己也照着做的时候，又发现不合自己的心意。

问题不在于你，而在于那是**别人**的答案。每个人被什么点亮，被什么激励，都不一样，只有你自己的感受才说了算。

HAND 想帮你找回两样东西：一是**对生活的掌控感**，日子怎么过，由你自己来安排；二是**更丰富、更滋养的生活**，一周里不只有忙碌和疲惫，也有让心灵舒展的小事。

所以 HAND 不给你标准答案，只提供一个框架，帮你**记录每件事做完之后有多开心**。三四周后回头看，哪些事值得留下、哪些可以舍弃，数据会帮你整理。

## 三个核心概念

把一周想象成一首歌 🎵

### ⚓ 锚点：主旋律

每周固定在某一天做的事，比如周五 Movie Night、周二和周四健身。

它们给生活一个节奏感：还没到周五，就已经开始期待电影夜了。但锚点**不要太多**，2–3 个刚刚好，多了就从「期待」变成「任务清单」了。

菜单里的任何一件事都可以设为锚点。某件事做了几次都很喜欢，就让它固定下来吧。

### 🍱 菜单：副歌

一份属于你的「生活菜单」，装着能让日子更丰富的事，分成五类：**滋养感官、探索城市、创造与输出、纯粹快乐、连接**。比如逛菜市场、探一家新咖啡馆、画画、给远方的朋友打个电话……

一开始不知道放什么？菜单页的**灵感库**里有现成的建议，点一下就能加进来，也可以自己写。

每周日花 5 分钟，看看心情和天气，从里面挑 1–2 个放进弹性时段。今天想出门就选「探索城市」，想窝着就选「纯粹快乐」，没有对错。

### 🌙 留白：前奏

至少留一个晚上，**什么都不安排**。

留白不是偷懒，而是给自己喘息的空间。没有留白的计划安排得再完美，很快也会让人感到疲惫。在这个 app 里，留白也可以打分：空着的那一晚，你感觉怎么样？

## HAND 里有什么

| 页面 | 功能 |
|---|---|
| **本周** | 看这一周的锚点、弹性、留白。点开任何一项：锚点从你的锚点里挑，弹性从菜单里挑，或者「随机来一个」。做完后打个 1–5 分，再写一句「为什么」。 |
| **菜单** | 你的生活菜单，按「日常节奏 / 滋养感官 / 探索城市 / 创造与输出 / 纯粹快乐 / 连接」分类。可以从灵感库添加，每件事都能一键设为锚点，删错了还能找回。 |
| **回顾** | 所有做过的事按开心程度排队。平均 4 分以上的可以一键「设为锚点」，2.5 分以下的建议删掉，不需要愧疚。你写过的每一句「为什么」也都在这里。 |
| **节奏** | 编辑每周的默认安排，新的一周都从这里开始。锚点太多、或者忘了留白时，它会温柔地提醒你。底部的「设置」里可以切换外观（浅色 / 深色 / 跟随系统），也可以登录账号、备份和恢复数据。 |

## 使用手册

1. **打开**：点击上方链接。在手机浏览器里选「添加到主屏幕」，它会像一个普通 app 一样待在你的桌面上。
2. **选一个开始方式**：第一次打开时有三个选择：
   - **先看看示例**：载入一份示例菜单和两周记录，看看它怎么用。准备好了，在「本周」页顶部点「清除示例，开始我的记录」，示例的菜单、安排和记录都会一起清掉。
   - **直接开始**：从空白开始，去灵感库挑几件想试试的事。
   - **已经有账号？登录**：换了新手机或新电脑，登录后直接接着用。
3. **搭好你的节奏**：在「节奏」页定下哪天是锚点、哪天留给弹性、哪天留白。
4. **每周日 5 分钟**：给弹性时段挑好这周想做的事。
5. **做完打分**：打个分，写一句话，记录自己当下对做这件事的感受。
6. **三四周后回顾**：高分的事件留下或升级成锚点，低分的事件放手，let it go~

## tips

- **想在多台设备上用？登录就好。** 点右上角的「登录 · 云端同步」，用 Google 账号或邮箱注册登录后，记录会自动保存到云端，换手机、换电脑登录同一个账号就能接着用。
- 不登录也完全可以用，只是记录**只存在当前这个浏览器里**。换手机、换浏览器或清理浏览器数据之前，记得去「节奏 → 设置 → 备份与恢复」复制一份备份。
- **在中国大陆使用**：app 可以打开，记录、打分、回顾都能正常用，但登录和云端同步依赖 Google 的服务，不翻墙时连不上。可以先在本地使用，靠「备份与恢复」保存数据。
- 整个 app 就是一个 `index.html` 文件，不需要安装或构建，用浏览器直接打开就能跑。登录和同步使用 Firebase，每个人只能读写自己的数据。
